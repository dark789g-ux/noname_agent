# 身份模式与 Get 模块化

## 入口与职责

公共路径不变：

- `apps/core/mode/identity.js`：导出 `type` 和模式工厂。
- `apps/core/noname/get/index.js`：导出 `Get`、活绑定 `get`、`setGet`、`Is`、`Promises` 及原 JSDoc 类型。

提取出的实现、类型契约与运行夹具均使用 TypeScript。入口、实现、契约、测试均纳入 500 行限制；不靠压缩排版满足限制。

| 目录                                      | 职责                                                                |
| ----------------------------------------- | ------------------------------------------------------------------- |
| `mode/identity/startup`                   | 保留启动、录像、新手引导阶段的原调度顺序                            |

## 普通身份控制流

```text
准备身份和座位 → 冻结候选 → 主公选择 → 本人选择
    → 其余座位选择 → 初始化收尾
```

普通身份通过单个 async content 显式等待子选择。每轮具有 `complete`、`restart`、`cancel` 状态：

- 保留原阶段间的子事件队列清空点和中间结果发布时机，避免初始化钩子创建的子事件越过收尾。
- 切换身份取消旧子选择并重建界面、候选和 LLM 轮次，不再写数字 `step`。
- 换座保留已选结果，沿用现有选将服务重新校验最终桌位。
- 设置、重选、自由选将和延迟创建界面的回调受轮次有效性保护。
- 重启不额外触发 `chooseButtonCancelled` 玩法事件。
- 取消或异常退出清理控件与活动选将服务；不继续初始化后续座位。

明忠、谋攻、紫色、联机、乱斗及引导保持原执行机制；即使乱斗使用普通身份子模式，也不强制迁移其私有调度约定。广播回调仍仅依赖可远程获得的引擎全局和显式参数，不捕获新模块 helper。

## 兼容约束

- `Get` 只有一个公共类；方法按原顺序通过描述符安装到其直接原型。
- 233 个方法名、函数名、参数长度、非枚举性、可覆盖性均有运行时基线。
- 四个函数协议方法继续不可写、不可重新配置；私有品牌仍由 `Get` 持有。
- 全局 `get` 和 `this` 的既有区别保留；缓存不复制到各方法模块。
- JS 未注解参数原有的可省略调用语义保留；显式 JSDoc 重载不放宽。
- `GetRuntime.d.ts` 的内部扩充指向实际类模块，防止声明生成把公共转发入口复制成另一个私有品牌。
- 旧 `var` 跨分支、跨循环共享的绑定在必要时显式提升为函数内 `let`，不改成不同的循环闭包。
- 不修复无关旧玩法问题；类型断言不增加运行时默认值或改变异常时机。

## 使用与未覆盖边界

无需新增配置、依赖或存档迁移。更新时部署完整构建产物，不要只覆盖两个入口文件；结束当前对局后完整刷新客户端，以免热更新留下旧原型或旧事件。

正常调用方无需修改导入。依赖普通身份私有 `contents[0..2]` 或数字 `step` 的扩展需调整其内部接入，公开选将入口和原有玩法钩子不变。

自动验证包含单/双将、LLM 顺序/并发/回退/取消/日志、实际设置重启、4500 组态度基线、介绍与延迟皮肤回调、声明和独立构建。浏览器真实布局、Electron、移动设备及多客户端联机仍需实机验收；没有调用真实付费模型。
