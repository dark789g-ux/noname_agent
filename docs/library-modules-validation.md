# Library 拆分验收记录

本次以执行开始时的工作区为基准，保留原有存储、LLM、模式及其它未提交修改。

## 交付范围

- `apps/core/noname/library/index.js`：从约 15,500 行缩减为 **425 个物理行**。
- 入口与实现共 121 个源文件，其中 117 个 TypeScript 文件；除入口外，卡牌注册表、运行状态和元素注册表这三个开放对象保留 JavaScript，以兼容原有动态扩展类型语义。
- 范围内最大源文件是 `network/client/reconnect.ts`，**435 行**。检查包含空行、注释、类型文件及配套测试。
- 迁移 14 个 Library 行为测试文件及 LLM 的目标范围测试，加载真实模块；保留不属于本次拆分的其它源码测试装载方式。
- 新增模块契约、初始化读时机、实例隔离、实时单例引用、结构基线和行数检查，并接入 `test:selection`。
- 模块职责和维护约束见 [Library 模块职责与验证](library-modules.md)。

一次与多个类型检查并行的回归运行曾出现 Node 原生内存不足退出。测试脚本已将回归与事件契约的并发数限制为 4，独立重跑全部通过。

## 兼容性证据

- `Library` 的 134 个成员名称、声明种类和顺序保持一致。
- 拆分前各实例字段的数据、键顺序、回调参数个数及描述符结构摘要与拆分后相同。
- 对原有 733 个函数体去除类型、注释和排版后比较语法树，732 个保持一致。剩余一个是 Boss 扩展的 `onswitch`：其中导入回调委托给 `configuration/importBoss.ts`，原回调体完整保留，并由原来的三个行为测试验证。
- 实例隔离、内置技能对象共享、战法构造副作用、Proxy 动态注册、实时 `setLibrary` 引用以及原型描述符通过真实模块测试。
- 重连测试调用完整的客户端 `reinit` 处理函数，验证回调接收者、参数顺序、对象身份及破坏性 `shift` 行为。
